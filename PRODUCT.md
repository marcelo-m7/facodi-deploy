# Product

## Register

product

## Users

Internal Odoo users, administrators, and operational teams who work in the backend for long sessions across settings, CRM, contacts, projects, website, learning, lists, forms, kanban views, dialogs, and relational fields.

## Product Purpose

Monodoo is a reusable backend identity and usability layer for Odoo Community. It should make the complete Odoo backend feel coherent while preserving standard Odoo workflows and allowing company, website, and user theme preferences to compose without per-screen CSS patches.

## Brand Personality

Clear, technical, reliable.

## Anti-references

Avoid fragmented screen-specific overrides, unreadable low-contrast dark interfaces, decorative dashboard styling, excessive rounded cards, hardcoded colors, and themes that only cover the navbar while leaving standard Odoo surfaces unchanged.

## Design Principles

- Semantic tokens are the single visual contract shared by Monodoo and standard Odoo components.
- Theme identity is composable: base, company, website, user preference, and light/dark mode resolve values without duplicating stylesheets.
- Operational density stays readable, predictable, and calm across long backend sessions.
- Standard Odoo components should work with the theme automatically when new modules are installed.
- Visual changes must preserve keyboard access, focus visibility, and WCAG 2.2 AA contrast.

## Accessibility & Inclusion

Target WCAG 2.2 AA for text, controls, focus states, disabled states, and theme switching. Respect reduced motion and system color-scheme preferences, while allowing explicit user light or dark choices to persist across reloads.
